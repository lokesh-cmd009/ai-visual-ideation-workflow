## 📌 Project Overview

Modern digital marketing demands rapid, high-velocity creative testing across multiple channels and ad formats. Traditional manual asset creation creates production bottlenecks, resulting in slow turnaround and inconsistent visual branding.

This project outlines an **AI-augmented creative workflow** developed through practical application of Kaggle AI generative frameworks:
1. **Rapid Conceptual Exploration:** Structured prompt engineering for lightning-fast style iteration, mood boarding, and asset prototyping.
2. **Style Consistency Framework:** Ensuring brand fidelity across diverse generative outputs using parameter controls and aesthetic anchors.
3. **Modular Template Architecture:** Pre-engineered, responsive Figma and Canva layout components that adapt generated assets into multi-platform deliverables in minutes.
4. **Data-Driven Ad Variants:** Systematic generation of high-converting visual ad variants with targeted Calls-to-Action (CTAs) for multivariate performance testing.

---

## 🚀 Key Features of the Interactive Studio

The interactive web application (`index.html`) serves as a live demonstration of the workflow:

* **Modular Prompt Engineering Workbench:** Interactive prompt constructor allowing designers to combine subjects, aesthetic mediums, lighting styles, camera perspectives, and mood palettes into optimized generative prompts.
* **Live Prompt Compiler:** Instant string synthesis with copy-to-clipboard functionality, ready for deployment in generative models.
* **Style Consistency & Mood Board Gallery:** Filterable visual asset cards showcasing varied aesthetic explorations (Cyberpunk, Swiss Minimalist, 3D Claymorphism, Studio Photorealism).
* **Responsive Template Layout Switcher:** Visualizing how modular visual assets snap into Instagram Feed (1:1), Story/Reels (9:16), and Display Banner (1.91:1) formats.
* **A/B Performance Testing Simulator:** Comparative conversion analytics showcasing click-through rates (CTR), engagement metrics, and visual hierarchy evaluation.
